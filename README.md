# LifeOps (codename)

> Forward it. Photograph it. Forget about it. LifeOps remembers.

A web-first personal + household administration operating system: it turns unstructured information (bills, receipts, warranties, insurance, contracts, appointments, maintenance, and more) into structured, actionable records — obligations, reminders, and a searchable life graph — so a household doesn't have to run its own filing system.

**Status:** Phase 0 (research) complete. No application code exists yet. See [PROJECT_STATE.md](PROJECT_STATE.md) for exactly where things stand and [ROADMAP.md](ROADMAP.md) for the full phase plan.

## Principles
- **Zero-capital until revenue.** Prefer open-source, free tiers, and usage-based services; no paid dependency without a documented alternative comparison.
- **AI is an implementation detail.** The product is a persistent life operating system, not a chatbot with a dashboard.
- **Trust and scope discipline over feature breadth.** Every close competitor researched in Phase 0 has a documented trust failure (surprise paywalls, opaque fees, business fragility) or a documented overwhelm failure (breadth without triage) — see [docs/research/pain-points.md](docs/research/pain-points.md). LifeOps is designed against both.
